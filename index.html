⭐ Featured Project

PLAYVREHAB

Kinect-based Serious Game for Physical Rehabilitation

Published · IEEE Xplore · ATEE 2025

The Problem

Physical rehab exercises are repetitive, dull, and hard to monitor without constant clinical presence. Patient engagement drops, and clinicians lose visibility into session data, leading to poor adherence and incomplete recovery records.

The Solution

PLAYVREHAB is a Unity-based serious game that turns rehabilitation exercises into interactive gameplay using a Kinect sensor for real-time skeletal tracking. A separate clinician web dashboard (PHP/MySQL) lets therapists monitor sessions and manage patient profiles with no room presence required.

Tech Stack

Unity · C# Kinect SDK MySQL PHP HTML/CSS

Architecture

The Unity client handles real-time Kinect skeletal tracking and game logic. Session data such as reps, errors, exercises completed is written to a MySQL backend via PHP REST endpoints. The clinician dashboard, a standalone PHP/HTML interface, reads and presents this data in a clean session-review format.

Key Highlights

  • Real-time body tracking via Microsoft Kinect SDK — no controllers, no barriers to entry for patients
  • Progressive difficulty system and feedback loops designed with serious game principles to maintain engagement
  • Full patient database with CRUD operations for clinician management
  • Session monitoring dashboard accessible remotely — not just a game, a clinical tool
  • Research paper published and indexed at IEEE Xplore following ATEE 2025 conference

What I learned

PLAYVREHAB forced me to bridge game feel and clinical utility, two things that rarely want the same thing. I learned to design for users who aren't players, build a multi-component system where game and dashboard stay in sync, and write research that holds up to academic peer review.

Turn-Based Strategy Game

Programming and Generation of Virtual Worlds — Unity 3D

Overview

A fully playable turn-based strategy game built from scratch in Unity for the Programming and Generation of Virtual Worlds course at ISCTE-IUL. Designed and developed collaboratively with Rui Jesus, covering everything from procedural world generation to turn management systems, AI opponents, and custom Unity shaders.

What we built

  • Procedural environment generation with custom terrain and asset placement pipelines
  • Turn-based game loop with state management, action queuing, and win condition logic
  • Custom ShaderLab / HLSL shaders for visual environment effects
  • Unit movement, combat resolution, and strategic AI behaviour systems
  • Full playable build with game flow from start to end state

Tech Stack

Unity · C# ShaderLab HLSL Procedural Gen

What I learned

This project deepened my understanding of game architecture at a systems level, how to structure a turn-based loop cleanly, how procedural generation decisions ripple through the rest of your design, and how Unity's rendering pipeline works under the hood via custom shaders. Collaborating with a co-author also sharpened how I split and own different subsystems within a shared codebase.

Collaborators
